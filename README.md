# darkshadow-smp-website

Professional website for the DarkShadow SMP Minecraft server.

## Overview
DarkShadow SMP Website provides information, server rules, join instructions, and community resources for the DarkShadow survival multiplayer (SMP) Minecraft server.

## Features
- Server information and rules
- Player guides and FAQs
- Links to apply, report issues, or join community chat
- Mobile-responsive site

## Tech stack
- Static website (HTML/CSS/JS)
- Hosting: GitHub Pages or your chosen hosting provider

## Installation & Local Development
1. Clone the repository:

```bash
git clone https://github.com/Krit2-droid/darkshadow-smp-website.git
cd darkshadow-smp-website
```

2. Open the site locally by opening the HTML files in your browser or use a simple HTTP server:

```bash
# using Python 3
python -m http.server 8080
# then visit http://localhost:8080
```
